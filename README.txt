Chxlbyzada — TrollStore iOS wrapper

Este proyecto contiene el HTML original dentro de una app WKWebView.
El workflow de GitHub Actions genera un IPA arm64 sin firma, apto para
instalación mediante TrollStore.

1. Sube esta carpeta a un repositorio de GitHub.
2. Abre Actions > Build TrollStore IPA > Run workflow.
3. Descarga el artefacto Chxlbyzada-TrollStore-IPA.
4. Abre el IPA con TrollStore.

Requisitos de compilación: macOS runner con Xcode; dispositivo iOS compatible
con la versión mínima indicada en Info.plist (iOS 14+).
